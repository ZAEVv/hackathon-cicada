РАСПРЕДЕЛЁННЫЙ РЕЕСТР

Решение по декларации нельзя тихо переписать

Каждое действие с декларацией — запись в журнале. Записи сцеплены хэшами: правка любой старой записи ломает всю цепочку.

Голову цепочки подписывают три независимых узла-свидетеля, каждый со своим ключом и своим хранилищем. Запись считается заверенной, когда подписали минимум двое.
