# Распределение работы

Агенты работают в одном новом репозитории, каждый владеет отдельными файлами.
Общие интерфейсы зафиксированы до запуска параллельной реализации в `CONTRACTS.md`.

| Роль | Модель | Область |
|---|---|---|
| Архитектура | OpenAI GPT-6.1 Sol | Контракты и схемы |
| История, каталог, погода | DeepSeek Flash | data.py |
| Прогноз и оценка модели | OpenAI GPT-6.1 Sol | predictive.py |
| Маршрутизация и стыковки | OpenAI GPT-6.1 Terra | routing.py |
| Оформление и аудит | OpenAI GPT-6.1 Terra | preclearance.py |
| ESG | DeepSeek Flash | esg.py, методика |
| Интерфейс | OpenAI GPT-6.1 Terra | frontend/ |
| Материалы защиты | DeepSeek Flash | DEMO, PITCH, REQUIREMENTS |
| Независимое ревью backend | DeepSeek V4 Pro | REVIEW_BACKEND |
| Финальное ревью по уточнению пользователя | OpenAI GPT-6 Astra | REVIEW_ASTRA |
| Сквозное QA | OpenAI GPT-6 Luna | test_api.py, demo.py |
| Интеграция | Основная сессия оркестратора | main.py, окружение, запуск, итоговые проверки |

Реализация выполнена без дочерних агентов Astra. По последующему прямому указанию
пользователя финальное ревью поручено Astra; отчёт DeepSeek — дополнительный.
Независимые пакеты разрабатывались параллельно; ревью и сквозное QA выделены
отдельным агентам.
