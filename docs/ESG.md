# ESG: расчёт выбросов CO2e по оставшимся участкам маршрута

Демонстрационный модуль `backend/app/esg.py` считает **ориентировочную оценку
выбросов только от перевозки** для оставшихся участков маршрута. Это не
сертифицированная методика и не отчётность о выбросах. Все коэффициенты —
иллюстративные значения демонстрационного контракта `v1`.

## Область расчёта (границы)

Учитываются только те участки, которые переданы в `legs`. Вызывающая сторона
(маршрутизация) обязана передать **только оставшийся путь**: уже выполненные
участки в расчёт не входят.

Что **не** учитывается:

- терминальные операции, погрузка/разгрузка, ожидание и хранение;
- порожние перегоны и перестановки транспорта;
- производство топлива и транспортных средств, инфраструктура, жизненный цикл
  (well-to-wheel и полный жизненный цикл не рассчитываются);
- прочие газы, кроме агрегированного CO2e, и косвенные выбросы цепочки поставок;
- социальные, стоимостные и иные ESG-показатели.

Модуль не проверяет расписание, пропускную способность, допустимость груза или
стоимость. Это ответственность маршрутизации. ESG-модуль только пересчитывает
переданные расстояния и режимы транспорта.

## Формула и единицы

Для каждого участка:

```text
co2_kg_i = (mass_kg / 1000.0) * distance_km_i * factor[mode_i]
```

Итого:

```text
total_kg = Σ co2_kg_i
```

Единицы:

| Величина | Единица | Комментарий |
|---|---|---|
| `mass_kg` | кг | масса груза; делится на 1000 для перевода в тонны |
| `distance_km_i` | км | расстояние участка |
| `factor[mode]` | кг CO2e / (т·км) | иллюстративный коэффициент на тонно-километр |
| `co2_kg_i`, `total_kg` | кг CO2e | результат и сумма по участкам |

Коэффициенты версии `v1`:

| Режим (`mode`) | Коэффициент, кг CO2e / (т·км) |
|---|---:|
| `rail` | 0.022 |
| `road` | 0.105 |
| `sea` | 0.016 |

Пример ручного расчёта (как в контракте): груз 20 000 кг = 20 т.

```text
море: 20 * 600 * 0.016 = 192 кг CO2e
авто: 20 * 357.14285714285717 * 0.105 = 750 кг CO2e
итого: 192 + 750 = 942 кг CO2e
```

`by_leg_kg` сохраняет порядок входных участков. `total_kg` равен сумме
`by_leg_kg`. Внутри расчёта округление не выполняется: сохраняется обычная
точность `float`; округлять можно только при отображении. Результат является
JSON-совместимым словарём и соответствует `schemas.Emissions`:

- `total_kg` — суммарные кг CO2e;
- `by_leg_kg` — список кг CO2e по каждому переданному участку;
- `factor_version` — `"v1"`;
- `factors_kg_per_tonne_km` — копия таблицы коэффициентов;
- `disclaimer` — текстовая оговорка о демонстрационном характере оценки.

## Допустимые значения и ошибки

Для сводки исторических перевозок `summary.py` использует интенсивность
`Σ CO₂e текущих маршрутов / Σ массы грузов в тоннах`. В обе суммы входят
только маршруты с известными оставшимися участками: недоступный маршрут без
участков означает отсутствие оценки, а не безэмиссионную перевозку.
Продолжение после пропущенной стыковки учитывается, если его участки рассчитаны.
Если известных участков нет вообще, API возвращает числовой ноль как отсутствие
данных; это не свидетельство нулевых выбросов. Исторический CO₂e — иллюстрация
по текущей структуре маршрутов, не измерение прошлых рейсов.

- `legs` должен быть списком словарей; пустой список допустим и даёт
  `total_kg = 0.0`, `by_leg_kg = []`.
- `mass_kg` должен быть конечным неотрицательным числом. Ноль допустим и даёт
  нулевые выбросы. Отрицательные, `NaN`, `±Infinity`, строки, `None` и `bool`
  отклоняются с `ValueError`.
- `distance_km` каждого участка должен быть конечным неотрицательным числом.
  Ноль допустим и даёт ноль для этого участка. Отрицательные и неконечные
  значения отклоняются с `ValueError`.
- `mode` обязателен и должен быть одним из `rail`, `road`, `sea` (с учётом
  регистра). Неизвестный или нестроковый режим отклоняется с `ValueError`;
  автоматического выбора коэффициента нет.
- Отсутствующие `mode`/`distance_km`, не-словарь в `legs` и не-список `legs`
  также отклоняются с `ValueError`.
- Дополнительные поля участка (`service_id`, `origin_id`, `cost_usd`, готовое
  `co2_kg` и т. п.) игнорируются. Выбросы всегда пересчитываются из `mode` и
  `distance_km`, поэтому устаревшее или подделанное поле `co2_kg` на результат
  не влияет.
- Входные данные не изменяются. Возвращаемая таблица коэффициентов и список
  `by_leg_kg` являются новыми объектами; их изменение не влияет на следующие
  вызовы.

## Оговорка о методике

Коэффициенты `0.022`, `0.105` и `0.016` — **иллюстративные демонстрационные
значения**, а не официальные или сертифицированные коэффициенты. Результат:

- не является расчётом по сертифицированной методике;
- не подтверждает соответствие GLEC, ISO 14083, ISO 14064, GHG Protocol или
  иным стандартам;
- не является оценкой полного жизненного цикла (WTW / LCA);
- не предназначен для обязательной отчётности, углеродных рынков, налогов,
  пошлин, таможенных или юридически значимых документов;
- не является аудированной или верифицированной величиной.

Любые публикуемые значения должны явно сопровождаться пометкой
«иллюстративная транспортная оценка, не сертифицирована» и указанием версии
коэффициентов `v1`. Успешный вызов функции означает только корректность
арифметики и входных данных, а не достоверность методики или реальных
операционных данных.
